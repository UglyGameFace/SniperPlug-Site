Confirm the Discloud side

  1. Make sure the key is saved in the canonical SniperPlug Discloud app environment as SNIPERPLUG_OPS_INGEST_SECRET with no extra quote marks, spaces or pasted variable name in the value.
  2. Restart the app after changing its environment. An already-running Python process cannot pick up a newly saved environment variable without restarting. First preserve a verified backup of the production SQLite database.
  3. Check the current Discloud logs for Operational telemetry enabled or Operational telemetry delivery. A 401 means a key mismatch; a 404 indicates the endpoint isn't reachable; a 422 points to invalid telemetry. Never share or log the key itself.
  4. Use Check again here. A received signed report proves connectivity, not the accuracy of each retailer listing.
